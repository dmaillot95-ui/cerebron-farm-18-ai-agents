# CÉRÉBRON Ω — Farm 18 AI Agents

Mission: développer et auditer des architectures d'agents IA, orchestration multi-agent, planification, mémoire, outils, routage, évaluation, sécurité, coûts et synthèse.

Règles:
- REALITY > COHERENCE
- CLAIM <= EVIDENCE
- AGENT COUNT != INTELLIGENCE
- SAME MODEL/DATA != INDEPENDENT EVIDENCE
- TOOL CALL != SUCCESS UNTIL VERIFIED
- MEMORY != LEARNING
- SIMULATION != TEST
- VERIFY BEFORE COMMIT

Pipeline:
PLAN -> ROUTE -> EXECUTE -> VERIFY -> RED TEAM -> REPLICATE -> SYNTHESIZE.

Toute sortie IA est UNREVIEWED_EXTERNAL_AGENT_OUTPUT tant qu'elle n'est pas vérifiée.
